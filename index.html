Case Studies

Military Service Project

Legacy Server Migration

Modernizing a Legacy SQL Server 2000 / Windows 7 Environment

General Directorate of Cooperatives, Labour and Social Welfare of Gilan Province | Compulsory Military Service (IT & Software Support), 2 Years

Problem: Several departments, including Unemployment Insurance and Labor Inspection, relied on internal software connected to a shared organizational server. Because the server had to run SQL Server 2000 on an old database, it was kept on Windows 7. As a result, the organization's antivirus software could not run on the server, the server occasionally became unstable, and the connected applications ran slowly for staff during daily work.

Solution: I identified the root cause as a compatibility conflict between the legacy database and the operating system. Using VMware Workstation, I built a test environment on the latest Windows Server release and migrated the SQL database files into it, connecting securely to the organization's real server data to validate compatibility under realistic conditions. I documented the full process and results in a technical description.

Result: The migration test completed successfully, showing the organization a clear path off the vulnerable legacy stack. I received formal recognition and a certificate of appreciation from the organization for this initiative.

Enterprise Project

Studio Performance Optimization

Restoring Workstation Speed & Stability for Multi-PC Studios

Photography Studios & Business Clients in Rasht | On-site IT Services

Problem: Photography studios and service shops running heavy image editing suites experienced severe workstation slowdowns, boot delays, and random software crashes due to fragmented disk storage, unoptimized startup services, and outdated driver configurations.

Solution: I executed an on-site comprehensive audit of the multi-PC environment, replacing failing mechanical drives with high-speed SSD storage strategies, removing background bloatware, updating critical graphics and chipset drivers, and tuning operating system registry parameters for maximum rendering responsiveness.

Result: Workstation boot times decreased by over 60%, application launch lag was eliminated, and studios achieved continuous, stable daily operations without crashing during heavy rendering tasks.
